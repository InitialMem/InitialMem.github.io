## Bitwarden中暴露的密码次数的计算方式

首先计算你的密码的哈希值SHA-1，然后只发送前几位，和泄露密码的数据库进行比对，数据库返回匹配该前缀的大量哈希，然后bitwarden在本地计算是否命中，这个数字代表的是密码在已知的泄露数据的数据库中出现的次数，即使次数为1次，也建议更改

## 睡眠和休眠

睡眠和休眠目的都是为了保留工作现场，最主要的区别是工作现场的保存位置不同。

睡眠将程序的状态保存在内存中，需要通电，如果断电可能会丢失未保存的数据

休眠将内存中程序的状态压缩后保存在磁盘中，此后电脑完全断电，断电一般不会丢失数据

如果不需要保留工作现场，那么这两个功能都没有必要。

在有持续电力供应或者电脑不依赖电池的情况下，选择睡眠，功耗减少，不占用磁盘空间，但是可能丢失数据。（台式机，插电运行的游戏本）

如果电量有限，又希望保留现场，选择休眠，其实电脑默认就启用休眠，每次开关机大多数都属于从休眠中唤醒，同时快速启动就依赖休眠。

```cmd
:: 查看两者是否开启
powercfg /a
```

## 画素描的反思

画了很多素描，但是没有注意到投影边缘应该锐利，明暗交界线应该稍微模糊。

1. 画之前没有确定目标，需要关注的东西太多，目标模糊，认为画好的状态就是大概像

2. 在画物体，而没有在画关系，很多人想的是眼睛画好没有，这个苹果画的圆不圆，而不是这里的明暗关系是否正确，边缘的软硬是否正确

3. 没有建立检查的意识，每画完一张都要检查：明暗交界线有没有最暗？投影是不是整体偏暗？投影边缘有没有比物体边缘硬？反光有没有超过灰面？高光是不是最亮？

**如何解决**

1. 每次只联系一个知识点：今天只处理二分形状，只练习找明暗交界线，只练反光

2. 画之前提出问题：今天我要验证投影边缘是不是最硬？然后在画的时候问现在这里够硬了吗？

3. 画完检查：大的明暗关系对了吗？明暗交界线画对了吗？

4. 建立错误库：画之前看下之前犯的错误，这次尽量避免

## pnpm的安装

pnpm是nodejs的第三方包管理器，类似npm，和官方的npm的区别如下：

1. 安装包的方式和存储方式不同，pnpm会将第三方包同一放在全局的存储区，不同的项目通过硬/软链接的方式提供，npm会在每个项目的node_modules下都下载一份

2. node_modules更严格，package.json中没有明确引用的包不能直接访问，因为一个依赖可能间接引用了其他依赖，而package.json中没有，但是项目里可以import这个幽灵依赖

**使用corepack安装pnpm**

corepack是包管理器的管理器

首先启动pnpm的命令代理，由corepack处理pnpm命令

```cmd
corepack enable
```

然后执行安装命令

```cmd
corepack install --global pnpm@latest
```
